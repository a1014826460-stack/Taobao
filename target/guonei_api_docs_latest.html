国内平台图片采集 API 对接说明

采集管理
接口概览 数据表结构 接口一：推送采集结果（爬虫端） 接口二：获取图片数据（清洗端） 接口三：标记清洗完成（清洗端） 状态流转 完整示例 对接注意事项

接口概览

接口 方法 地址 用途
推送采集结果 POST /guonei/api_push.php 爬虫端采集完成后推送图片数据到数据库。
获取图片数据 GET /guonei/api_fetch_result.php 清洗端拉取采集已完成的数据，拉取后自动标记为「已取出」。
标记清洗完成 POST /guonei/api_fetch_result.php 清洗端处理完成后回传，将数据标记为「已清洗」。
建议流程：爬虫采集 → 调用推送接口存入数据库 → 清洗端调用获取接口拉取数据 → 清洗完成后调用标记接口回传确认。

数据表结构

guonei_keywords（关键词任务表）

字段 类型 说明
platformvarchar(50)平台：淘宝、京东

image_typevarchar(20)图片类型：首图、套图
sort_typevarchar(20)排序类型：销量、综合
page_countint(11)采集页数
expected_countint(11)预计采集数量
statusvarchar(20)任务状态：待采集、采集中、已完成、失败

guonei_images（图片结果表）

字段 类型 说明
platformvarchar(50)平台：淘宝、京东
keywordvarchar(100)搜索关键词
image_typevarchar(20)图片类型：首图、套图
sort_typevarchar(20)排序类型：销量、综合
page_numint(11)采集页码
product_urlvarchar(500)商品链接
product_titlevarchar(500)商品标题
image_urlslongtext图片URL数组JSON
image_countint(11)图片数量
crawl_statusvarchar(20)采集状态：待采集、采集中、已完成、失败
clean_statusvarchar(20)清洗状态：待清洗、已取出、已清洗
clean_channelvarchar(100)清洗渠道
fetched_atdatetime取出时间
cleaned_atdatetime清洗完成时间

接口一：推送采集结果（爬虫端）

请求方式

POST，必须 Content-Type: application/json

请求参数

参数 必填 说明
items是推送数据数组，或直接传单条对象
platform是平台：淘宝、京东
keyword是搜索关键词
image_type是图片类型：首图、套图
sort_type是排序类型：销量、综合
page_num否采集页码
product_url否商品链接
product_title否商品标题
image_urls是图片URL数组
crawl_result否采集结果详情JSON

请求示例

curl -X POST "/guonei/api_push.php" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      {
        "platform": "淘宝",
        "keyword": "润滑液",
        "image_type": "首图",
        "sort_type": "销量",
        "page_num": 1,
        "product_url": "https://item.taobao.com/item.htm?id=123456",
        "product_title": "xxx润滑液",
        "image_urls": ["https://img.alicdn.com/imgextra/i1/xxx.jpg"],
        "crawl_result": {"status": "success"}
      }
    ]
  }'

返回示例

{
  "success": true,
  "message": "推送成功",
  "success_count": 1,
  "failed_count": 0,
  "results": [
    {"success": true, "id": 1, "message": "推送成功"}
  ]
}

接口二：获取图片数据（清洗端）

请求方式

GET

请求参数

参数 必填 说明
channel是清洗渠道标识
limit否最多拉取数量，默认1，最大100
mode否拉取模式：new（默认）、refetch
platform否筛选平台：淘宝、京东
keyword否关键词模糊匹配

模式说明

mode 获取范围 用途
new采集已完成且清洗状态为「待清洗」的数据正常获取全新待清洗数据
refetch清洗状态为「已取出」但尚未清洗的数据清洗失败后重新取出，防止数据遗漏

请求示例

curl "/guonei/api_fetch_result.php?channel=cleaner_01&limit=10&mode=new&platform=淘宝"

返回示例

{
  "success": true,
  "message": "获取成功",
  "channel": "cleaner_01",
  "limit": 10,
  "mode": "new",
  "count": 1,
  "items": [
    {
      "id": 1,
      "platform": "淘宝",
      "keyword": "润滑液",
      "image_type": "首图",
      "sort_type": "销量",
      "page_num": 1,
      "product_url": "https://item.taobao.com/item.htm?id=123456",
      "product_title": "xxx润滑液",
      "image_urls": ["https://img.alicdn.com/imgextra/i1/xxx.jpg"],
      "image_count": 1,
      "crawl_status": "已完成",
      "clean_status": "已取出",
      "clean_channel": "cleaner_01",
      "fetched_at": "2026-07-25 10:00:00"
    }
  ]
}

接口三：标记清洗完成（清洗端）

请求方式

POST，必须 Content-Type: application/json

请求参数

参数 必填 说明
channel是必须和获取时使用的channel一致
items是待标记的ID数组，或直接传单条对象
id是数据主键ID

请求示例

curl -X POST "/guonei/api_fetch_result.php" \
  -H "Content-Type: application/json" \
  -d '{
    "channel": "cleaner_01",
    "items": [{"id": 1}, {"id": 2}]
  }'

返回示例

{
  "success": true,
  "message": "标记清洗成功",
  "channel": "cleaner_01",
  "success_count": 2,
  "failed_count": 0,
  "results": [
    {"success": true, "id": 1, "clean_status": "已清洗"},
    {"success": true, "id": 2, "clean_status": "已清洗"}
  ]
}

状态流转

阶段 clean_status 说明
待清洗NULL / 待清洗采集已完成，等待清洗端取走
已取出已取出系统自动设定，记录渠道和取出时间
已清洗已清洗清洗端回传确认，记录清洗完成时间

完整接入示例

爬虫端：推送采集结果

POST /guonei/api_push.phpContent-Type: application/json

{"items": [{"platform": "淘宝", "keyword": "润滑液", "image_type": "首图", "sort_type": "销量", "image_urls": ["https://..."]}]}

清洗端：获取待清洗数据

GET /guonei/api_fetch_result.php?channel=cleaner_01&limit=10&mode=new

清洗端：重新取出已取出数据（清洗失败后重试）

GET /guonei/api_fetch_result.php?channel=cleaner_01&limit=10&mode=refetch

清洗端：标记清洗完成

POST /guonei/api_fetch_result.phpContent-Type: application/json

{"channel": "cleaner_01", "items": [{"id": 1}, {"id": 2}]}

对接注意事项

  • 平台仅支持：淘宝、京东
  • 图片类型仅支持：首图、套图
  • 排序类型仅支持：销量、综合
  • 首图：销量排序采集20页（约500张）+ 综合排序采集10页（约500张）= 合计1000张/关键词/平台
  • 套图：综合排序采集4页（约200套）/关键词/平台
  • 标记清洗时 channel 必须和获取时完全一致，否则会被拒绝
  • 如果一条数据已经标记为「已清洗」，再次标记会返回"该数据已清洗，无需重复提交"
